# 2026-09-05

## App Store Build 9 用户可访问素材库修复

- Apple 再次拒绝 `0.1.4 (Build 8)`：上一版只将手动导出改为 `NSSavePanel`，权威原始录音、系统音轨、会议混音和导入素材仍写入隐藏 App Container。
- Build 9 首启通过 macOS 标准保存面板创建用户可直接访问的“Woice 素材”文件夹；用户取消时录音和导入 fail-closed，不回退到 Container 创建新素材。
- 麦克风录音、系统音轨、会议混音、导入原件和派生音频、滚动录音块与侧车文件统一使用该外部素材文件夹；删除事务也不再把音频搬入 Container 暂存。
- 素材文件夹通过 security-scoped bookmark 持久授权。Build 8 旧文件复制后逐文件 SHA-256 校验，校验成功才移除旧副本；同名不同内容、符号链接或校验失败均不覆盖原文件。
- 应用中断恢复延后到素材文件夹已授权且旧文件已迁移之后；Store 设置只展示用户选定的素材文件夹及 Finder 入口，不展示 Container 路径。
- `CFBundleVersion` 和 `DistributionManifest` 已递增到 9；隐私政策改为如实说明用户选定素材文件夹，Review Notes 为 3547 字符。
- 新增 4 项素材库回归：迁移/哈希/重启书签恢复、冲突不覆盖、拒绝 Container 位置、取消 fail-closed。
- `make verify` 通过：274 项 Swift Testing + 18 项 XCTest，并通过文档、Harness、资源、连接器、lint 和本地打包门禁。
- `make store-capability-check` 通过：252 项 Store 条件 Swift Testing + 18 项 XCTest。`make xcode-build-store` 和 `make verify-app-store` 通过：双架构 Store Bundle、Build 9 资源、沙盒用户选择读写权限、零模型与二进制边界有效。
- 尚未执行：Apple Distribution Archive、实体 Mac 首启/迁移/录音/导入/重启验收、上传、App Store Connect 更新与重新提交。
