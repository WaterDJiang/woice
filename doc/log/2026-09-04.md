# 2026-09-04

## App Store Build 8 审核修复

- Apple 对 `0.1.4 (Build 7)` 指出三项问题：用户文件导出位于隐藏 Container、非辅助用途的 Accessibility 权限，以及需补充系统声音捕获说明。
- Store 版音频、TXT、JSON 和 Markdown 导出已统一改为 `NSSavePanel`；取消打开/显示 Container 内部素材入口，用户自行选择可访问的保存位置。
- `TextInsertionService`、模拟 Command-V、自动/手动粘贴和 Accessibility 权限入口已从 `WOICE_APP_STORE` 编译排除；二进制门禁新增 AX 符号检查。
- ScreenCaptureKit 仅注册 `.audio` 输出，不注册 `.screen`；`PRIVACY.md` 已补齐数据、用途、共享、存储、保留和可引用原文。
- Build 号递增为 8，Review Notes 共 2814 字符，低于 4000 字符限制。
- 定向 Material Export 3 项、Store Bundle verifier 5 项、官网配置 270 项 Swift Testing + 18 项 XCTest 和 Store 配置 247 项 Swift Testing + 18 项 XCTest 通过。
- `make verify`、`make store-capability-check`、`make xcode-build-store` 与 `make verify-app-store` 全部通过；Store 双架构构建、沙盒权限、资源、零模型和二进制边界均通过。
- 待完成：正式 Archive/上传、实体 Mac 的导出与权限流程验收，以及 App Store Connect 回复和重新提交。
