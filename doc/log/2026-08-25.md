# 2026-08-25 开发记录

## 双音源、压缩存储与长素材详情

- 工作台和菜单栏增加“麦克风”“电脑声音”两个独立来源按钮，默认双开；任一可关闭，两者全关时禁止开始并显示“请至少开启一个音源”。录音中来源锁定。
- 麦克风单轨只启动 `AVAudioEngine`；电脑声音单轨只启动 ScreenCaptureKit；双开保留两条原轨并生成会议合成文件。
- 新录音改为 AAC/M4A：麦克风 64 kbps、电脑声音 128 kbps、会议合成 64 kbps；ASR 需要时再生成 16 kHz 工作文件。旧 WAV/CAF 不转码、不覆盖。
- 会话 Journal 增加 `captureMicrophone` 并兼容旧数据；异常恢复系统音频单轨时不再伪造麦克风或会议合成。
- 详情页取消打开时同步预加载全部音轨，改为单一播放器和三个音轨选择按钮；点击播放才加载当前文件。原文与时间轴使用固定高度独立滚动，时间轴使用 `LazyVStack`。
- SwiftUI UI Pattern 约束用于原生按钮状态、键盘/VoiceOver 语义和懒加载滚动结构。

## 录音控制区视觉层级

- 按 `ui-ux-pro-max` 的主次动作层级与 `swiftui-ui-patterns` 的原生控件约束，菜单栏 Popover 将“录音来源”整理为独立中性设置区；麦克风和电脑声音用图标、文字、细边框和勾选表达状态，不再与主动作同时铺满蓝色。

- 导入与开始录音仍保留在素材库空状态；快速音源选择和录音保留在菜单栏 Popover，不在工作台顶部重复。`RecordingSourceControl` 只服务菜单栏，四种来源组合使用同一摘要，并保留录音中锁定来源、Help、VoiceOver 和 Reduce Motion 语义。
