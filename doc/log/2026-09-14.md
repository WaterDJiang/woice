# 2026-09-14

## 16 kHz 麦克风 AAC 录音兼容性修复

- 复现：当前运行的 `/Applications/Woice 2.app` 为 `0.1.5 (Build 10)`；设置页显示麦克风 `16,000 Hz / 1 声道`，点击录音后出现 `The operation couldn’t be completed. (com.apple.coreaudio.avfaudio error 560226676.)`。
- 根因：`RecordingAudioFormat.aacSettings` 固定请求 `64 kbps AAC`。macOS 在 `16 kHz / 1 声道` 创建编码器时，`AudioConverterSetProperty(... kAudioConverterEncodeBitRate ...)` 返回 Core Audio `!dat`（`560226676`）。
- 证据：修复前的 `sixteenKilohertzMicrophoneAACUsesSupportedBitRate` 同时断言得到 `64,000` 而非 `48,000`，并原样捕获上述 `com.apple.coreaudio.avfaudio` 错误。
- 修复：AAC 参数按采样率选择不超过请求值的兼容码率；16 kHz 使用 `48 kbps`，48 kHz 的麦克风 `64 kbps` 和系统声音 `128 kbps` 保持不变。主 M4A、滚动块和恢复重建复用同一规则。
- 回归：`swift test --no-parallel --filter sixteenKilohertzMicrophoneAACUsesSupportedBitRate` 通过；`WOICE_REQUIRE_MIC_AUDIO=1 swift test --no-parallel --filter microphoneRecordingServiceWritesM4AAtCurrentInputRate` 通过；此前的 `microphoneRecordingServiceWritesFrames` 和 `systemAudioStreamStartsAndStops` 真实门禁也通过。
- 边界：未覆盖安装包；当前运行实例仍需重新构建并按本机签名规则安装后，才能在 UI 中使用修复。未修改历史音频、用户数据或另一发行 Channel。

## 工作台录音停止入口

- 复现：工作台展开后，WorkspaceView 只有素材空状态中的“开始录音”；录音中主窗口没有停止按钮，停止入口只在菜单栏 Popover。
- 修复：在工作台内容列顶部加入共享 AppState 的录音会话状态条，显示状态、时长、实际音源和“结束并保存”；录音中切换路由或收起侧栏仍保留该入口。
- 交互：停止按钮调用现有 AppState.stopRecording()；实时文字预览移到状态条下方的正常布局，避免遮挡停止按钮；未新增暂停、丢弃或独立计时状态。
- 测试：新增 WorkspaceRecordingControlsTests；swift test --no-parallel --filter WorkspaceRecordingControlsTests 通过；make test 通过（286 项、18 个套件）；make lint 与 make xcode-build-direct 通过。
- 边界：当前没有有效 WOICE_LOCAL_SIGNING_IDENTITY，未覆盖安装 /Applications/Woice (Dev).app，也未替用户启动真实录音；REC-02/UI-01 的真实 Mac Journey 待稳定签名安装后验收。
