## App Review 2.1(a) 模型清单更新修复

- Apple 审核记录：MacBook Air (15-inch, M3, 2024)、macOS 26.6.1、Woice 0.1.4 (Build 6)；点击“检查更新”显示错误。
- 通过本机网络只读请求固定 GitHub Raw 地址，确认返回 `HTTP 200`、正文为 JSON，但 `Content-Type: text/plain; charset=utf-8`；该行为来自 GitHub Raw，不是 Qwen 推理或模型下载错误。
- 根因：`ModelCatalogFetcher` 只接受 `application/json` 或 `+json`，在 Catalog schema、Catalog ID、版本和 Ed25519 验签前拒绝了合法正文。
- 修复：兼容 `text/plain` 响应；正文仍必须经过既有 JSON 解码、schema、签名、信任历史和版本门禁，`text/html` 等非 JSON 类型继续 fail-closed。
- 验证：`swift test --no-parallel --filter ModelCatalogTransportTests` 通过，4 项测试（含 GitHub Raw `text/plain` 回归）；随后 `make test` 通过（270 项 Swift Testing + 18 项 XCTest），`make verify`、`make verify-app-store`、`make docs-check`、`make harness-check` 和 `git diff --check` 均通过。
