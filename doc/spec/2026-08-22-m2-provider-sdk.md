# M2-07 受控进程 Provider SDK 契约

> 状态：契约基础本轮实现；签名验证和运行时进程编排待后续

## 1. 目标

冻结外部进程 Provider 的 Manifest、来源和信任状态，确保后续 ASR/LLM/TTS 进程接入不会穿透 Runtime 边界，也不会加载任意动态库。

## 2. 范围

- Manifest 包含稳定 ID、显示名、语义版本、Provider 类型、可执行文件绝对路径、固定参数和能力列表。
- Validator 拒绝空 ID、非法版本、相对路径、路径穿越和未知 Provider 类型。
- Provider 来源区分随 App 签名内置、用户安装和外部来源；信任状态独立记录。
- 契约对象不包含 API Key、Prompt、音频内容或任意环境变量。

## 3. 不在本工作包

- 不运行外部进程，不实现动态库加载，不把 Provider 输出直接写入数据库。
- 不宣称已完成 Developer ID 签名、公证、代码签名验证或沙箱隔离。
- 进程超时、输出上限、环境白名单和工作目录由下一工作包实现，并必须附真实子进程测试。

## 4. 验收标准

- 合法 Manifest 能编码/解码并保留来源与信任状态。
- 非法 ID、版本、相对路径、路径穿越和未知类型均 fail-closed。
- 旧代码编译、`make verify` 通过；测试不读取或提交真实密钥。
