# M2-03b 结构化笔记区块

> 状态：本轮实现；不改变原始转录或 Markdown 派生文件

## 目标

把 Markdown 笔记中的“要点”和“待办”在录音详情页以可扫读的原生 UI 展示，同时保留完整 Markdown 原文供复制、导出和复核。

## 范围

- 解析常见的 Markdown 标题、无序列表、有序列表和任务列表。
- 识别“摘要/要点/重点/总结”和“待办/行动项/TODO”区块；兼容旧响应中直接出现的“待办：”条目。
- 待办为空或明确写“暂无”时显示“暂无待办”，不把它误报成一条任务。
- 解析失败或没有结构化条目时仍显示原始 Markdown，不阻断转写、导出或朗读。
- 结构化展示是对 `generatedMarkdown` 的只读投影，不创建或覆盖 Artifact。

## 验收标准

- 固定 Markdown Fixture 能稳定得到要点和待办数组，顺序与原文一致。
- 旧式无标题列表和带 `待办：` 前缀的响应保持可读；明确“暂无”不会生成任务。
- 详情页同时提供要点、待办和 Markdown 原文，原文可选中复制。
- `make verify` 与 `make acceptance-core` 继续通过。
