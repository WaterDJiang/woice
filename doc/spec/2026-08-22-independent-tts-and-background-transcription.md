# 文字转音频独立模块与录音后台转写规格

> 状态：实施中
> 替代：修正 M2-06 中“录音详情页内置朗读”的入口设计。
> 保留：macOS `AVSpeechSynthesizer` 的本机朗读能力；录音、原始 WAV、ASR 和模型版本快照仍是核心。
> 迁移：录音详情页的朗读入口迁移到独立“文字转音频”窗口；长录音转写迁入录音分段与本机后台任务。
> 停止：录音完成后自动触发朗读；不新增云端/本地 TTS Provider、语音克隆或自动外发。
> 顺序：先切断录音链路中的 TTS 触发，再提供独立 TTS 入口；本机分段固化后串行后台转写，录音结束时合并结果。

## 1. 问题与目标

- 录音的主链路只允许“录音 -> 原始音频保存 -> 转成文字”；不得因为转写完成而自动播放或生成音频。
- 文字转音频是独立工具：用户可以粘贴文字，或导入 `.txt`/`.md` 文件，再显式点击“朗读”。
- 长会议使用已关闭的声音片段作为后台本机 ASR 输入；前面的片段在录音继续时排队处理，结束录音时只补齐最后片段并合并。
- 外部 ASR 仍必须在录音固化后逐次取得外发确认；不得在录音期间隐式上传片段。

## 2. 用户流程

### 2.1 录音与转写

1. 用户开始录音，菜单栏显示录音状态、时长、麦克风输入和后台转写阶段。
2. 本机 VAD 关闭一个声音片段后，Woice 把该片段固化为独立临时 WAV，并在后台串行交给当前本机模型。
3. 录音继续进行；失败片段保留错误，不阻塞麦克风录音。
4. 用户停止录音，主 WAV 先完成提交；最后未关闭的片段随后固化并转写。
5. 所有成功片段按时间排序合并为原文和时间戳；无法完整合并时回退到已固化主 WAV 的整段本机转写。

### 2.2 文字转音频

- 通过菜单栏“文字转音频”打开独立窗口，不在录音详情页展示朗读卡片。
- 输入来源二选一：编辑文字，或导入 UTF-8 `.txt`/`.md` 文件；导入后允许继续编辑。
- 只有用户点击“朗读”才调用 macOS 系统语音；支持暂停、继续、停止和重新朗读。
- 窗口关闭、录音完成、转写完成均不得自动调用 TTS。
- 支持显式导出 WAV；导出只写用户选择的目标路径，失败保留错误且不影响录音素材。

## 3. 技术与数据边界

- `SpeechPlaybackService` 只由独立 TTS 窗口持有；`RecordingDetailView` 不持有、不初始化、不调用它。
- `AudioWriter` 在主 WAV 之外按 VAD 关闭事件写入独立片段文件；片段文件在 ASR 任务完成后可删除，主 WAV 永不删除或覆盖。
- 后台转写仅允许 `shouldUseLocalASR == true` 且本机 Provider 已具备授权/模型；未授权时只显示等待，不触发 TCC 请求。
- 本机 Provider 任务串行执行，避免 WhisperKit/系统 Speech 并发争用；任务结果只回写当前录音的派生 Transcript Artifact。
- 任何外部 ASR 仍走现有 `ExternalProcessingRequest` 和确认队列；分段文件不得绕过确认直接外发。
- 原始录音的 SHA-256、文件名和保存位置不因分段转写改变。

## 4. 验收标准

- AC-TTS-001：停止录音后不会出现系统朗读；转写完成后不会出现系统朗读。
- AC-TTS-002：录音详情页没有朗读区块；独立窗口可导入 `.txt`/`.md`、编辑文字，并在显式点击后朗读。
- AC-TTS-003：TTS 窗口支持暂停/继续/停止；空文字不会启动朗读。
- AC-TTS-004：用户显式点击“导出 WAV”并选择目标路径后才生成音频文件；录音完成和转写完成均不会触发导出。
- AC-BG-001：本机模型已就绪时，录音未停止前至少一个已关闭声音片段进入后台转写队列。
- AC-BG-002：录音停止先提交主 WAV，再等待最后片段；已有片段不重复整段处理。
- AC-BG-003：后台失败不删除主 WAV；界面显示失败片段和可重试状态，外部服务未被调用。
- AC-BG-004：后台片段结果按时间顺序合并；合并不完整时使用已固化主 WAV 进行一次回退转写。
- AC-BG-005：录音期间不自动请求 Speech 权限、不自动上传外部 ASR；退出或崩溃不会伪造“已完成”。
