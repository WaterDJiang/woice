# 设置页与菜单栏操作体验

> 状态：由 2026-08-23 优化计划收口实施
> 日期：2026-08-22
> 关联：[产品定位](2026-08-22-voice-context-source-positioning.md) · [设置 UI 设计](../design/2026-08-22-settings-ui-ux.md)

## 1. 目标

让用户在不离开菜单栏主流程的情况下完成三件事：

- 快速判断 Woice 当前是否可录音、是否已配置本机转写。
- 在设置页明确知道自己正在修改哪一类设置，以及更改何时生效。
- 从菜单栏图标位置找到历史、设置和退出 Woice 等应用级操作。

## 2. 范围

### 2.1 设置页

- 侧栏保留录音与输入、模型与转写、文件与隐私，并将 Agent 与连接作为低频只读分区。
- 每个侧栏项同时显示图标、标题、摘要和当前状态；选中项必须有系统高亮。
- 详情页顶部显示当前分区标题和解释，避免用户只看到表单字段而失去上下文。
- 设置继续使用草稿隔离：编辑只改变草稿，点击“保存设置”后才提交；未保存状态提供“还原”。
- 保存状态、错误和 Keychain/外发说明固定在底部操作栏；不使用乐观的“已保存”。
- 支持键盘导航、VoiceOver、浅色/深色和高对比模式；图标只使用 SF Symbols。
- 模型设置必须提供版本控制：显示当前使用版本、已安装版本和“切换/回滚”动作；切换只影响后续转写。
- 文件与隐私页显示 Woice App 版本和 Build，便于反馈问题时定位运行版本。

### 2.2 菜单栏图标菜单

- 菜单栏图标点击后保留录音状态、主动作和最近结果。
- 菜单栏底部提供“进入工作台”“设置”和“退出 Woice”三个应用级动作。
- “退出 Woice”使用破坏性语义、与普通导航动作分隔，并提供明确的 VoiceOver 文案。
- 退出动作必须终止当前应用实例，不删除录音、模型或设置数据。
- 录音进行中点击退出时，先确认“保存录音并退出”；退出不静默丢弃未固化音频。

## 3. 非目标

- 不把设置页改成 Agent 控制台或模型市场。
- 不新增自定义图标库、复杂动画或网页式仪表盘。
- 不在退出动作中增加数据清理、缓存删除或永久删除行为。

## 4. 验收标准

- AC-SET-001：打开设置后，用户能在侧栏一眼区分录音与输入、模型与转写、文件与隐私。
- AC-SET-002：每个详情页首屏显示当前分区标题、用途说明和表单内容。
- AC-SET-003：修改字段后出现未保存提示；点击“还原”恢复基线；关闭窗口不提交草稿。
- AC-SET-004：保存成功只在 `AppState.saveSettings` 返回成功后显示；保存失败保留错误并继续显示草稿。
- AC-SET-005：菜单栏弹窗可直接打开历史、设置和退出 Woice；三项动作均有文字和 SF Symbol。
- AC-SET-006：退出 Woice 后不删除任何用户数据；下次启动仍能读取历史、设置和模型库存。
- AC-SET-007：键盘焦点顺序与视觉顺序一致，退出动作可被 VoiceOver 读为“退出 Woice”。
- AC-SET-008：录音中点击退出会先出现确认；选择“保存录音并退出”后完成停止录音，再终止应用。
- AC-SET-009：模型版本控制显示当前版本和已安装版本；切换已验证版本后，下一次本机转写使用新版本。
- AC-SET-010：切换模型版本不修改历史录音、原始转录或既有模型版本快照。
- AC-SET-011：文件与隐私页显示 App 版本和 Build 信息。

## 5. 影响面

- `Sources/WoiceApp/SettingsView.swift`：设置导航、详情页头部和操作栏。
- `Sources/WoiceApp/Views.swift`：菜单栏弹窗的应用级操作。
- `Sources/WoiceApp/WoiceApp.swift` 与 `WoiceMenuBarController.swift`：使用单一 AppKit `NSStatusItem` 与 `Settings` 场景，不新增第二个菜单栏入口；状态栏 Popover 和工作台窗口共享同一 AppState/Router。
