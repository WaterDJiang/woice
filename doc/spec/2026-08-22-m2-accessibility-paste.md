# M2-04 辅助功能粘贴

> 状态：本轮实现；固定 `⌥Space` 全局录音快捷键已接入，配置化快捷键仍为独立工作包

## 1. 目标

让用户在转写完成后，能够把原文显式粘贴到当前前台应用；用户主动开启后，也可在转写成功时自动粘贴。默认不申请辅助功能权限、不自动向其他应用注入文字。

## 2. 范围

- 录音详情提供“复制原文”和“粘贴到当前应用”两个明确动作。
- 设置页提供关闭状态、权限检查和“转写完成后自动粘贴”开关，默认关闭。
- 首次执行粘贴时才触发 macOS 辅助功能权限提示；拒绝时保留原文并给出系统设置入口。
- 通过系统剪贴板写入文本，再发送一次明确的 Command-V；不模拟录音、不绕过外发确认。

## 3. 不在本工作包

- 不实现 Fn/Globe、单修饰键或 Event Tap 全局快捷键。
- 不在后台静默粘贴，不把原文发送给目标应用以外的网络服务。
- 不把 Accessibility 权限当成首次启动必需权限。

## 4. 验收标准

- 默认配置不触发辅助功能权限请求，历史设置缺少字段时仍可读取。
- 未授权时粘贴动作 fail-closed，原文仍保存在 Woice，错误提示包含下一步。
- 授权后显式粘贴写入当前应用；自动粘贴只在用户打开开关且转写成功后执行。
- `make verify` 通过，录音/转写/复听 smoke test 不回归。
