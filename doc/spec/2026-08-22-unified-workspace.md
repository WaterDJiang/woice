# Woice 统一工作台规格

状态：统一工作台与音视频连续转写已实现；侧栏上下固定布局由[WCL-01](../plan/2026-08-24-current-technical-development-closure.md)实施与技术验收

## 背景

当前“查看录音文件”“文字转音频”“设置”分别打开独立窗口。每个窗口本身可用，但用户需要在多个工作台之间切换，录音素材、处理任务和设置之间没有连续上下文。

## 目标

- 以一个主窗口承载 Woice 的素材管理与后续操作。
- 保留菜单栏 Popover 的快速录音定位，不把菜单栏变成管理后台。
- 借鉴 Codex/Co 的持续工作区信息架构：左侧导航、中间内容、右侧上下文详情；不引入聊天中心或通用 Agent 控制台。
- 录音转文字仍是核心链路；文字转音频在同一工作台内保持独立工具边界。
- 增加本地音视频导入入口，让“选择文件 -> 导入完成 -> 转文字 -> 打开新素材”形成与录音一致的连续闭环。

## 范围

### 工作台结构

- 新增唯一 `Window("Woice 工作台", id: "workspace")`。
- 左侧导航包含：素材库、处理任务、文字转音频、设置。
- 侧栏必须占满窗口可用高度：素材库、处理任务、文字转音频固定在顶部，设置固定在底部，只有当前工作区的搜索、筛选和列表位于中部并独立滚动。
- 工作台首次打开和重新启动时默认显示侧栏；工具栏与“窗口”菜单必须提供“显示/隐藏侧边栏”，用户隐藏后始终有明确恢复入口。
- 窗口放大、缩小或列表为空时，不得将整组导航垂直居中，也不得让素材列表把顶部功能或底部设置推出可见区。
- 素材库使用素材列表 + 素材详情；录制和导入内容共用播放器、原文、时间戳片段、AI 笔记和导出。
- 处理任务集中显示后台转写、失败原因、重试入口和模型状态。
- 文字转音频作为工作台内的独立页面，支持文字/文件输入、朗读和 WAV 导出，不接收录音自动触发。
- 设置作为工作台内的分区页面，保留录音与输入、模型与转写、文件与隐私三组和草稿保存语义。

### 菜单栏

- Popover 继续只提供开始/结束录音、状态、最近素材和打开工作台。
- 在录音主动作下增加次级“导入音视频…”入口；点击后打开工作台并进入统一导入流程，不在 Popover 内承载文件管理。
- “查看全部录音”“文字转音频”“设置”均通过工作台路由打开，不再创建独立窗口。
- 菜单栏录音状态、快捷键、外发确认和退出确认行为保持不变。

### 导入音视频连续流程

- 工作台仅在素材库和素材详情上下文持续显示“导入音视频…”次级动作，并与“开始录音”并列；设置、处理任务和文字转音频页不显示。
- 素材库无数据时同时提供“开始录音”和“导入音视频…”；不得把导入藏入省略号菜单或录音按钮的下拉菜单。
- 文件选择后使用持续存在的 Sheet 承载导入、准备、待转写、转写中、失败和完成状态；不得在导入完成后要求用户先回素材库寻找新文件。
- 导入完成后立即显示“转文字”主按钮；外部服务显示“确认并发送转写”，未选择模型时显示进入模型设置的可执行入口。
- 转写成功后关闭 Sheet，进入素材库并选中刚完成的素材，主内容区直接显示原文；失败时保留 Sheet、已导入原件和重试入口。
- 用户选择“稍后处理”时才关闭 Sheet并保留未转写素材；该动作是次级退出路径，不取代“转文字”主动作。
- 导入音频和视频保留不可变原文件；视频只提取音轨生成可复听、可转写的标准音频，视频无音轨、损坏或不支持时明确失败。
- 首版兼容 WAV、MP3、M4A、AAC、AIFF、CAF、FLAC、MP4、MOV 和 M4V；真实支持范围以系统解码和验收矩阵为准，不把扩展名选择成功等同于可转写。

## 路由与组件边界

- `WorkspaceRoute` 只描述 UI 路由：`.library`、`.processing`、`.textToAudio`、`.settings(SettingsSection)`、`.recording(UUID)`。
- `WorkspaceRouter` 由 App 组合根创建并注入环境；菜单栏只发送路由请求，不直接操作内容视图内部状态。
- `WorkspaceView` 负责窗口级布局和导航；`WorkspaceSidebar` 负责一级导航；原有 `RecordingDetailView`、`TextToAudioView` 和设置分区作为内容组件复用或拆分。
- 自建 `NSWindow` 内使用受控的双列 `HStack`；侧栏固定理想宽度、详情吸收剩余空间，工作台根视图按窗口 bounds 布局，避免 `NavigationSplitView` 的内容固有高度把顶部导航和底部设置推出可视区域。
- 导入流程使用窗口级 Sheet 状态，不新增一级工作区或常驻导航；完成后仍通过 `.recording(UUID)` 选择新素材，后续可在领域命名收口时统一调整路由名称。
- Domain、Runtime、Storage、录音和转写逻辑不因工作台改造而改变；UI 路由状态不得进入持久化录音模型。
- 工作台窗口最小尺寸建议为 1080 × 700 pt；继续支持浅色、深色、高对比、键盘导航、VoiceOver 和 Reduce Motion。

## 设计原则

- 一窗口连续上下文：切换素材、工具和设置不丢失主窗口位置与工作状态。
- 一屏一个主任务：素材库突出录音详情；文字转音频突出编辑器；设置突出保存；不在同一屏堆叠多个主 CTA。
- 安静的原生工具感：SwiftUI/AppKit 原生导航、系统字体、SF Symbols 和语义色；不做网页式 AI 仪表盘。
- Agent 后置：未来“发送给 Agent”只能出现在已完成素材的详情/处理动作中，不改变工作台首页的录音素材中心定位。
- 可恢复：切换页面不隐式保存设置，不停止后台任务，不删除或覆盖原始 Artifact。

## 验收标准

- AC-WORKSPACE-001：点击历史记录、文字转音频或设置，只打开同一个 Woice 工作台窗口，不产生三个独立工作台窗口。
- AC-WORKSPACE-002：工作台左侧能在素材库、处理任务、文字转音频和设置之间切换，当前页面有清晰选中状态。
- AC-WORKSPACE-003：素材库能选择录音并在同一窗口右侧显示详情、播放、原文、时间戳、AI 笔记和导出动作。
- AC-WORKSPACE-004：文字转音频仍需用户显式输入/导入和点击操作；录音转写完成后不会自动进入文字转音频页面或自动朗读。
- AC-WORKSPACE-005：设置切换分区和返回素材库时，未保存草稿仍遵循现有还原/保存规则。
- AC-WORKSPACE-006：菜单栏开始/结束录音不依赖工作台打开；录音期间工作台和 Popover 都显示一致状态。
- AC-WORKSPACE-007：工作台关闭后再次打开，不创建重复窗口；菜单栏退出仍按录音中确认规则执行。
- AC-WORKSPACE-008：`make docs-check`、`make harness-check`、`make lint`、`make test`、`make verify` 和 `make install` 通过。
- AC-WORKSPACE-009：素材库和素材详情工具栏持续显示“导入音视频…”与“开始录音”；其他工作区不显示导入主入口。
- AC-WORKSPACE-010：导入完成后，同一 Sheet 立即显示可执行的“转文字”，不要求用户先返回列表选择新素材。
- AC-WORKSPACE-011：转写成功后自动进入素材库、选中新素材并在主内容区显示原文；整个路径不需要再次寻找文件。
- AC-WORKSPACE-012：转写失败时原始导入文件仍安全保存，Sheet 显示原因、重试和稍后处理；不得生成虚假成功状态。
- AC-WORKSPACE-013：素材列表和详情以图标 + 文字区分录制、导入音频和导入视频，颜色不是唯一来源信号。
- AC-WORKSPACE-014：导入、重转写和后续处理前后，原始音视频 SHA-256 不变；录音与导入内容共用现有 ProcessingTask、Transcript Artifact、导出和 Agent 路径。
- AC-WORKSPACE-015：空素材库、长素材列表、最小高度和最大化窗口下，三个主功能始终贴近侧栏顶部，设置始终贴近侧栏底部。
- AC-WORKSPACE-016：中部上下文区自行吸收剩余高度并独立滚动；搜索、筛选和列表滚动不改变顶部导航与底部设置的位置。
- AC-WORKSPACE-017：新窗口默认显示侧栏；隐藏后可从窗口工具栏或“窗口”菜单恢复，隐藏状态不得跨 App 重启造成空白侧栏。

## 替代、保留、迁移、停止、顺序

- 替代：三个独立的历史记录、文字转音频和 Settings 工作台入口，改由统一 Workspace Route 承载。
- 保留：菜单栏快速录音 Popover、原始素材不可覆盖、后台转写、模型版本控制、文字转音频独立业务边界和设置草稿隔离；导入后复用既有素材与处理体系。
- 迁移：原 `HistoryView` 作为素材库内容；`TextToAudioView` 和设置分区作为工作台页面；导入文件只增加来源元数据和不可变原件，不迁移或重写旧录音数据。
- 停止：从菜单栏直接创建独立历史/文字转音频窗口；停止把 Settings scene 作为唯一设置入口；停止“导入后回列表再找文件并手动转写”的断裂流程。
- 顺序：统一工作台基础保持不变；侧栏容器和工具栏稳定后接入导入 Sheet、媒体准备与现有转写链，最后验证成功自动选中新素材和失败恢复。
