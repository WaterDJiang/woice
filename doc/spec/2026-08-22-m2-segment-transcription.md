# M2-02/M2-03 分段转写闭环

> 状态：本轮实现；实时增量上传和说话人分离仍待后续

## 1. 目标

消费 VAD 产生的 `voiceSegments`，从原始 WAV 临时抽取声音时间范围，调用用户配置的 ASR，并保存带时间起止的派生转录片段。

## 2. 范围

- 详情页在存在声音片段且没有原文时提供“按声音片段转写”。
- 一次用户确认后，按时间顺序串行发送每个临时 WAV，避免并发占用音频/网络资源。
- 每个成功片段保存 `TranscriptSegment(start,end,text)`，原文按顺序拼接。
- 临时分段文件在成功或失败后清理；原始 WAV 不修改、不删除。
- 分段任务有独立幂等键和失败状态，可从详情页显式重试。

## 3. 不在本工作包

- 不声称实时边录边传；停止录音后才启动分段任务。
- 不实现说话人分离、重叠语音处理或跨片段自动纠错。
- 不在没有用户确认时向 ASR 发送任何片段。

## 4. 验收标准

- 合法声音时间范围能抽取为可读 WAV，原始文件 SHA/大小不变。
- 自定义 ASR Fixture 返回多段文本后，历史记录保存顺序、起止时间和拼接原文。
- 任一片段失败时保留原始 WAV、已完成片段状态和可重试任务，不伪装为完成。
- 每个成功片段立即写入当前派生文本投影；后续片段失败时，已完成片段仍可查看和重试。
- `make verify` 和真实麦克风 smoke test 通过。
