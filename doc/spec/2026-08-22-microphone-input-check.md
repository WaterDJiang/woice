# 麦克风输入自检规格

## 背景

仅显示“权限已允许”不能证明当前输入路由真的产生了声音。用户需要一个可理解、可重复的本机诊断动作，区分权限问题、设备问题和低电平静音。

## 目标

- 在设置页提供“测试输入”动作，录制约 700 ms 的临时 WAV。
- 展示实际收到的音频缓冲数、采样时长和会话峰值；低电平时给出检查系统输入设备和静音状态的下一步。
- 当权限已允许但没有可用输入时，提供直达 macOS“声音 > 输入”设置的按钮，避免让用户手动寻找路由入口。
- 自检只写入系统临时目录，完成或失败后删除，不进入历史、不触发 ASR/LLM、不产生任何外发。
- 正在录音时禁止自检，避免两个 Audio Engine 会话互相干扰。

## 验收标准

- 已获麦克风权限且有可用输入时，点击“测试输入”能完成短暂采样并返回 bufferCount > 0、duration > 0。
- WOICE_REQUIRE_MIC_AUDIO=1 真实 Mac 回归要求 peakLevel > 0.0001；低于阈值时 UI 明确提示检查输入路由和静音。
- 自检生成的临时 WAV 在方法返回前可由 AVAudioFile 读取，返回后临时文件不存在。
- 录音进行中点击不会启动第二个采集会话，显示可读错误。
- 无可用输入状态下点击“打开声音设置”使用系统设置 URL；刷新后重新读取输入路由。
- make verify 通过，外发确认和录音历史数据不产生新增记录。

## 非目标

- 不做降噪、自动增益、系统音频采集或持续波形分析。
- 不将自检样本上传到任何 Provider。

## 影响面

- RecordingService：增加临时采样和峰值/帧数结果。
- SettingsView：增加输入测试按钮、进度反馈和可访问提示。
- 测试：增加真实授权 Mac 的临时 WAV 自检。
