# 菜单栏 Popover 前端优化规格

状态：由 `2026-08-23-menubar-settings-shortcut-optimization` 收口实施

> 2026-08-23 裁决：菜单栏是快速控制器，不再承载最近结果、导入、文字转音频或二级“更多”导航。空闲态固定为“开始录音、进入工作台、设置、退出 Woice”四个动作；Popover 高度跟随实际内容，目标 190～260 pt、上限 420 pt。

## 目标

让菜单栏入口回到“快速录音控制器”的定位：用户在一个短、稳定、可预测的界面里知道当前状态、开始/结束录音、查看最近素材，并把低频操作放到次级菜单。

## 范围

- 保留 AppKit `NSStatusItem` 和 336 pt Popover，不引入新的导航层或第二个菜单栏入口；工作台窗口使用 regular AppKit 窗口控制器。
- 空闲、录音中、处理中的状态使用同一布局，主按钮随状态变化。
- 录音中显示真实录音时长、麦克风输入电平和后台转写阶段；删除“15 分钟视觉刻度”这类会误导为有上限的 determinate 进度。
- “进入工作台”统一打开唯一工作台窗口；导入和文字转音频从工作台进入。
- 菜单栏空闲图标使用单色系统符号，保留全彩 Woice 资产用于 Popover 品牌标识和 App 图标；录音中使用红色录音状态与时长。
- 退出保持可见且可键盘操作；不使用破坏性红色语义，录音中仍需先确认保存。
- 保持状态同时使用图标和文字，并保留 VoiceOver、键盘快捷键、Reduce Motion 支持。

## 不在本轮

- 不改变录音、转写、存储、模型或后台任务领域逻辑。
- 不把菜单栏改造成历史管理、模型管理或 Agent 入口。
- 不新增独立的设计系统组件；仅抽取菜单栏需要的状态图标视图。

## 设计决策

| 区域 | 决策 |
|---|---|
| 顶部 | 全彩 Logo + Woice 产品承诺，保留品牌识别但不占用主操作空间 |
| 状态 | 图标 + 文字；录音状态用红色，错误用橙/红色，普通状态用语义色 |
| 主操作 | 单个全宽按钮；录音中为“结束录音”，空闲为“开始录音” |
| 进度 | 录音时长是无上限事实，使用计时器和输入电平；处理任务继续使用 indeterminate `ProgressView` |
| 次级操作 | “查看全部录音”直接打开历史；低频的文字转音频、设置、退出进入“更多” |
| 菜单栏图标 | 空闲单色 `waveform`，录音中红色 `record.circle.fill` + 时长；不直接显示全彩 PNG |

## 验收标准

- AC-UI-001：空闲 Popover 只有一个主录音按钮；打开后不再同时呈现四个同权重底部按钮。
- AC-UI-002：录音进行超过 15 分钟时，界面仍显示真实累计时长，不出现填满或自动停止的视觉暗示。
- AC-UI-003：录音状态同时显示录音时长与麦克风输入电平；处理状态显示阶段和不确定进度。
- AC-UI-004：点击最近结果卡片可打开历史窗口；文字转音频不出现在录音主操作区。
- AC-UI-005：空闲菜单栏图标为单色系统符号；录音时显示红色状态与时长；图标有 VoiceOver 标签。
- AC-UI-006：更多菜单包含文字转音频、设置和退出；退出不使用破坏性角色；录音中退出仍弹出保存确认。
- AC-UI-007：`make docs-check`、`make harness-check`、`make lint`、`make test`、`make verify` 与 `make install` 通过。

## 影响面与迁移

- 替代：旧 Popover 底部 2×2 同权重动作布局、录音 15 分钟视觉进度条、空闲状态直接使用全彩 Logo 的菜单栏图标。
- 保留：全彩 Logo 作为 Popover 头部和 App 图标；录音/转写/历史/设置的现有业务行为。
- 迁移：历史入口改名为“查看全部录音”，文字转音频与设置由“更多”菜单承载。
- 停止：任何暗示录音 15 分钟上限的视觉文案或比例进度。
- 顺序：先更新 Popover 结构和图标，再格式化与测试，最后打包安装并检查签名。
