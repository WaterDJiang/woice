# 全局录音快捷键

> 状态：基础实现完成；当前提供固定的 `⌥Space`，自定义按键和冲突检测留给后续工作包。

## 目标

让用户在不打开菜单栏 Popover 的情况下，用一个明确的键盘手势开始或结束录音；快捷键只是用户手势入口，不绕过麦克风权限、录音状态可见性、原始音频落盘或外发确认。

## 范围

- 使用 macOS 原生 `RegisterEventHotKey` 注册 `⌥Space`。
- 第一次按下调用现有 `AppState.startRecording()`；录音中再次按下调用现有 `stopRecording()`。
- 注册失败时保留菜单栏按钮可用，并在设置页显示失败原因。
- 应用退出或服务释放时注销快捷键和事件处理器。
- 设置页显示快捷键、启用状态和当前注册结果。

## 不在本次范围

- 自定义快捷键录制器、按键冲突检测和导入导出。
- Fn/Globe、单修饰键或 Event Tap/Input Monitoring 权限。
- 用快捷键触发录音以外的转写、外发、PI 工具或自动粘贴。

## 验收标准

- `⌥Space` 在 Woice 未聚焦时也能触发开始/结束录音；录音状态仍由现有菜单栏图标、时长和 Popover 显示。
- 快捷键触发不会在 `authorizing`、转写、生成或等待外发确认时重复启动任务。
- 系统拒绝快捷键注册时，App 不退出；设置页给出“菜单栏按钮仍可用”的下一步说明。
- `make verify` 通过，至少包含快捷键生命周期和 toggle 路由的单元测试。
- 不新增网络请求、API Key、音频文件格式或数据库 Schema。
