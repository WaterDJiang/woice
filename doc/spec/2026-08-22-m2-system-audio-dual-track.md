# M2-01 系统音频与麦克风双轨

> 状态：能力探针已实现，双轨落盘待后续工作包  
> 创建日期：2026-08-22  
> 关联计划：[`2026-08-22-m0-mvp.md`](../plan/2026-08-22-m0-mvp.md)

## 1. 目标

为会议模式建立系统音频与麦克风双轨采集的安全前置条件：在不改变现有麦克风录音链路的情况下，确认当前 Mac 的屏幕录制权限、可共享显示器和 ScreenCaptureKit 接入前置条件，并把结果用用户能理解的方式呈现。

## 2. 本工作包范围

- 使用 `CGPreflightScreenCaptureAccess()` 读取屏幕录制权限，不在打开设置时隐式弹窗。
- 在用户主动点击后调用系统授权入口，并允许用户回到 Woice 重新检查。
- 使用 `SCShareableContent.excludingDesktopWindows(_:onScreenWindowsOnly:)` 验证可枚举的显示器内容。
- 当前屏幕目标为空时允许一次 onScreenWindowsOnly: false 的能力回退；回退仍只显示能力状态，不自动开始采集。
- 在设置页显示“未授权 / 已授权但无可用显示器 / 可开始接入系统音频”三类状态。
- 记录系统音频正式接入前的约束：用户手势、权限、双轨独立文件、统一时间基准、失败不影响麦克风原始文件。

## 3. 不在本工作包

- 不自动开始系统音频采集。
- 不把屏幕画面写入录音文件。
- 不伪造双轨已完成；`SCStream` 音频 sample buffer 到独立 WAV/CAF 文件的落盘属于下一工作包。
- 不在权限失败时把系统音频静默降级成云端或麦克风替代品。

## 4. 验收标准

- `make verify` 通过，新增能力探针单元测试覆盖状态映射。
- 在 macOS 14+ 编译通过，未授权时设置页不崩溃、不退出、不开始录音。
- 点击“请求屏幕录制权限”后，状态能在用户返回 Woice 后通过“重新检查”刷新。
- 已授权且存在显示器时显示系统音频接入前置条件可用，但仍明确说明尚未开始采集。
- 没有可共享系统音频目标时，界面用用户可执行的语言说明解锁桌面/关闭远程桌面后重新检查，不直接暴露底层 ScreenCaptureKit 错误。
- 现有麦克风录音、WAV 落盘、时长显示和播放测试继续通过。
- 真实 Mac 上记录一次权限探针结果；在真实双轨落盘完成前，不得把 M2-01 标记为完成。

## 5. 影响面

- 新增 `SystemAudioCapabilityService`，只负责权限/能力读取，不接触录音文件和 Runtime 状态机。
- 设置页增加“系统音频（会议模式）”卡片。
- `Makefile` 文档门禁与 spec/log 索引增加本规格指针。
- 后续双轨实现必须沿用现有“用户控制录音、原始数据不可覆盖、失败可诊断”的项目约束。
