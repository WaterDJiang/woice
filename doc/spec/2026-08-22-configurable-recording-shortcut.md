# 可配置录音快捷键

> 状态：值模型、录入控件与自动测试完成；真实快捷键冲突和安装包体验仅作验收提醒。

## 目标

让用户在设置中选择一个可识别的系统注册式录音快捷键，或明确关闭快捷键；不安装 Event Tap，不额外申请 Input Monitoring 权限。

## 范围

- 支持键码 + `Command/Option/Control/Shift` 修饰键组合，保留 `⌥Space`（默认）、三个旧预设和“关闭”的兼容解码。
- 录入后保存前用独立 Carbon 探针检查；保存时先注册候选，失败时恢复原快捷键和持久化值。
- 快捷键只调用既有开始/结束录音入口，不能绕过麦克风权限、用户手势约束或外发确认。
- 旧设置 JSON 缺少新字段时回退到 `⌥Space`。

## 验收标准

- `AppSettings` 能编码/解码快捷键选择，旧 JSON 保持兼容。
- `GlobalShortcutService` 能按选择注册/注销，动态文案与错误信息对应实际按键。
- 设置页显示当前选择、启用状态和冲突后的恢复方式；选择“关闭”后不注册系统快捷键。
- `make verify`、快捷键服务测试和真实麦克风/ASR smoke 不回归。
