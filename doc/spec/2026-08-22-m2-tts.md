# M2-06 系统 TTS 与结果朗读

> 状态：能力保留，入口已迁移到独立文字转音频模块
> 替代：本文件中“录音详情提供朗读”的入口描述由[独立 TTS 与后台转写规格](2026-08-22-independent-tts-and-background-transcription.md)替代。
> 停止：云端/本地模型 TTS Provider、自动朗读和语音克隆。

## 1. 目标

为用户输入或导入的文字提供本机系统语音朗读和显式 WAV 导出，不上传文本、不改变原始录音和转录 Artifact。

## 2. 范围

- 独立“文字转音频”窗口提供编辑、导入 `.txt`/`.md`、朗读、暂停/继续、停止和导出 WAV。
- 录音详情不提供朗读区块；录音完成或转写完成不得自动调用 TTS。
- 使用 macOS `AVSpeechSynthesizer`，默认中文 voice，系统不可用时显示可读错误。
- 播放状态与原始 WAV/CAF 复听状态独立，离开详情页停止朗读。

## 3. 不在本工作包

- 不把文本发送到云端 TTS；WAV 只在用户显式选择目标路径后保存。
- 不实现语音队列跨 App 重启恢复、不实现 SSML 编辑器或说话人音色市场。

## 4. 验收标准

- 空文本不会启动朗读并返回明确错误。
- 朗读、暂停/继续、停止状态可观察，原始音频播放器不受影响。
- 独立窗口显示当前文字来源和朗读状态；录音详情不出现 TTS 状态。
- `make verify` 通过，录音、转写和复听 smoke test 不回归。
