# Woice App Icon 层说明

当前定稿是用户确认的 1254×1254 RGB PNG，已经把蓝色丝带、深色内折和微光作为一个不可拆分的视觉整体。

- 背景：定稿 PNG 内置的纯白背景。
- 前景：定稿 PNG 内置的蓝色 W 丝带、深色内折和微光。
- Xcode Icon Composer：当前使用同一张不透明 raster master 导入，不重新绘制、不叠加系统圆角、不补渐变。
- 生产真相：`../woice-final-ribbon-1254.png`；`../exports/AppIcon.appiconset/` 是尺寸导出。
- 旧版几何矢量分层位于 `../../archive/w-vector-v1/`，不再作为当前生产源。
