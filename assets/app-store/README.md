# Woice App Store 资产

本目录准备 Build 7 进入 App Store Connect 所需的资料和事实底稿；真实产品截图仍需从最终签名 Build 采集，不用宣传稿或生成图冒充产品界面。

## 文件

- `metadata-draft.md`：中文主商店页文案、英文 Review Notes 和账号侧待补字段。
- `screenshot-brief.md`：Mac 截图的画面顺序、文案和导出规格。
- `submission-checklist.md`：Build 7 提交前的资产、隐私、签名、公证和审核检查。
- `apple-submission-reference.md`：2026-08-24 Apple 官方截图、上传、隐私清单和审核资料链接快照。
