# Woice App Store 资产

0.1.5 已获 Apple 批准。本目录保留已批准资料，并准备 `0.1.6 (Build 11)` 的本地优先元数据与截图；已有候选图来自旧 Build，上传前仍需与最终签名 Build 11 逐张比对，不用宣传稿或生成图冒充产品界面。

## 文件

- `metadata-draft.md`：中文主商店页文案、英文 Review Notes 和账号侧待补字段。
- `screenshot-brief.md`：Mac 截图的画面顺序、文案和导出规格。
- `submission-checklist.md`：发行前的资产、隐私、签名、公证和审核检查。
- `apple-submission-reference.md`：2026-08-24 Apple 官方截图、上传、隐私清单和审核资料链接快照。
- `design/`：不含 UI 的品牌背景、生成提示词和真实截图包装脚本。
- `screenshots/build9-actual/`：Build 9 实机原始截图与 alpha 展平副本。
- `screenshots/build9-candidates/`：6 张 1280×800、无透明通道的下一版本候选图。
