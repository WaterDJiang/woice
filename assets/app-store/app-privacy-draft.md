# Woice App Privacy 答卷草案

> 这是 App Store Connect 填答前的事实底稿，不替代 Apple 后台的最终问卷。发布前必须依据最终依赖、网络请求和审核 Build 重新核对。

## 当前事实底稿

| 项目 | 草案结论 | 说明 |
|---|---|---|
| 是否跟踪用户 | 否 | 不使用广告、跨 App 跟踪或数据经纪服务 |
| 联系信息 | 不收集 | 无账户体系；API Key 只进入本机 Keychain |
| 用户内容 | 仅用户选择外发时处理 | 录音、转录、导出和模型默认本机处理 |
| 音频数据 | 仅本机保存或按用户确认发送 | 麦克风/系统声音是用户主动录音产生的素材 |
| 诊断数据 | 不收集 | 日志默认不记录完整音频、转录或 Prompt |
| 精确位置、联系人、健康、财务 | 不收集 | 产品无对应能力 |

## 发布前复核

- 核对最终 Store Bundle 的网络请求、第三方 SDK 和模型下载地址。
- 核对隐私政策 URL、支持 URL、删除/导出说明和审核备注。
- 若新增账户、遥测、崩溃服务或云端默认路由，必须重新填写，不沿用本草案。
