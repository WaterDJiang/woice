# Woice App Privacy 事实底稿（Build 7）

> 本文件按当前审核 Build 的代码、资源和网络边界整理；App Store Connect 仍需由有权限的账号提交最终答案。若新增遥测、账户或默认云端处理，必须重新填写。

## 当前事实底稿

| 项目 | 草案结论 | 说明 |
|---|---|---|
| 是否跟踪用户 | 否 | 不使用广告、跨 App 跟踪、指纹识别或数据经纪服务 |
| 开发者是否收集数据 | 否（默认） | 无账户、广告、遥测或崩溃分析后端；录音和转录默认仅保存在本机 |
| 联系信息 | 不收集 | API Key 只进入 macOS Keychain；不会上传到 Woice 服务 |
| 用户内容/音频 | 用户选择外发时由指定服务处理 | 仅在用户主动配置并确认后发送音频或文字；本机转写不外发 |
| 模型下载网络信息 | 托管方可能记录标准连接日志 | GitHub Raw/Hugging Face 只用于清单和模型文件请求，具体保留以其政策为准 |
| 诊断数据 | 不收集 | 日志默认不记录完整音频、转录、Prompt 或模型响应 |
| 精确位置、联系人、健康、财务 | 不收集 | 产品无对应能力 |

## 发布前复核

- App Store Connect 的“是否收集数据”按当前事实选择“否”；若将用户主动配置的第三方 ASR/LLM 视为第三方收集，按实际服务和数据类型补充“音频/用户内容”，并标注非跟踪、非广告用途。
- 隐私政策 URL：`https://github.com/WaterDJiang/woice/blob/main/PRIVACY.md`。
- 支持 URL：`https://github.com/WaterDJiang/woice/issues`。
- 提交前再次核对最终 Store Bundle 的网络请求、第三方 SDK 和模型下载地址。
