# 0.1.7 更新说明

## 简体中文

录音进度更清楚，等待转写更安心。

- 开始录音后，素材列表立即显示新的录音记录。
- 停止录音后，在同一条记录中持续显示保存和处理状态。
- 转写完成后直接查看原文与复听，无需重新查找记录。
- 改善保存期间的操作保护，避免重复操作。

## English

A clearer recording workflow, from start to transcript.

- New recordings appear in the library as soon as recording starts.
- Saving and processing status remain visible in the same entry after recording stops.
- Open the transcript and playback from that entry when processing finishes.
- Improved protection against repeated actions while saving.
