# 模型下载选择说明

## 目标

在设置页的本机模型下载列表中，同时保留一键下载能力，并让用户在下载前看见三个模型包对设备资源和转写产出质量的影响，能够按自己的 Mac 与使用场景选择。

## 范围

- 覆盖 Tiny、Qwen3-ASR 0.6B 4-bit、WhisperKit Large-v3 三个本机模型包。
- 在共用模型卡和设置页 Large-v3 条目中展示统一的设备影响、产出质量和选择提示。
- 不改变下载、断点续传、校验、原子安装、取消、重试或当前模型切换逻辑。
- 保留现有发行边界：Store/TestFlight 只展示已经过 Store 清单门禁的模型；Qwen3-ASR 在官网/Offline 版本继续可见，在 Store 版本保持隐藏，直到签名 Catalog、性能与审核门禁完成。

## 文案原则

- 资源影响描述以下载体积、运行时内存/电量倾向和启动速度为主，不伪装成精确的硬件基准。
- 质量描述使用“基础 / 平衡 / 最高”等选择级别；Large-v3 只声明已经通过的五类 300 秒性能门禁，不承诺所有真实会议都无偏差。
- Qwen3-ASR 的质量文案明确标为官网预览/平衡选择，不把尚未完成的正式性能矩阵写成已验证事实。
- 每个条目继续标注本机运行和不因下载而外发录音的隐私承诺。

## 验收标准

1. 三个模型条目各自显示预计下载大小、设备影响、产出质量和适用场景。
2. Tiny、Qwen3-ASR、Large-v3 的下载按钮仍调用现有 durable model download coordinator；已安装、下载中、等待、取消、失败和进度状态保持不变。
3. Store/TestFlight 构建中 Tiny 与 Large-v3 可见且可点击下载；Qwen3-ASR 不因本次文案改动绕过 Store 清单门禁。
4. 官网/Offline 构建中三个模型均可见并可独立下载和切换。
5. 新增模型选择说明的确定性测试；`make test`、`make lint`、`make verify` 通过。
