# 开放素材导出

## 目标

让已保存的录音素材可以脱离 Woice 使用：用户可从录音详情显式导出原始音频、纯文本原文、时间戳 JSON 和 Markdown。

## 范围

- 导出原始麦克风 WAV；若存在，则可分别导出电脑声音 CAF 和会议合成 WAV。
- 导出规范化纯文本 TXT，不包含 Whisper 协议 token 或界面标签。
- 导出包含录音元数据与转写片段的 JSON；没有时间戳时仍导出可解析的空片段数组。
- 保留已有 Markdown 导出；所有导出均为派生副本，不覆盖原始录音、原始转录或数据库记录。
- 导出目录使用设置中的目录，未设置时使用 Woice exports 目录；文件名稳定且避免路径穿越。

## 不在范围

- 自动同步、云端上传或 Agent 派发。
- 修改原始音频、原始转录或删除素材。

## 验收标准

- 详情页“导出”菜单显示四类导出；没有原文时 TXT/JSON/Markdown 给出明确反馈。
- 导出的 WAV/CAF 可由系统音频播放器或 AVAudioFile 打开。
- TXT 与详情页规范化原文一致；JSON 可被 JSONDecoder 解码并包含 id、duration、transcript、segments、音轨文件名。
- 导出失败显示原因和下一步动作；成功显示实际路径。
- 单元测试验证原始音频 SHA-256 和保存的 RecordingRecord 在导出前后不变。
