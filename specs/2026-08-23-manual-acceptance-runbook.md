# Woice 当前版本手动验收运行手册

## 使用范围

本手册用于补齐自动化不能安全代替的 macOS 权限、视觉和真实素材验收。当前安装包为稳定签名 Build `2026082406`；双轨合并、原文/来源分离、CLI 文字默认和素材废纸篓交互已修复，仍需重新确认真实会议原文同时包含两路内容。

当前证据目录：

```text
/private/tmp/woice-stable-ab-20260823-task-a11y-projection
```

其中包含本轮 `Woice-Stable-A.app`（Build `2026082331`）、`Woice-Stable-B.app`（Build `2026082332`）以及 `task-a11y-projection` 标签的覆盖前备份；更早的导入失败语义包仍见 `media-import-failure`，任务投影包仍见 `resumable-projection`、`task-projection`，导入页修复包仍见 `media-sheet-fix`。不要删除 `~/Library/Application Support/Woice`，不要调用 `tccutil reset`。

CLI 文字默认与素材废纸篓修复已覆盖安装 A/B（Build `2026082405` → `2026082406`），证据目录为 `/private/tmp/woice-stable-ab-20260824-text-only-trash`；当前手册以已安装 Build `2026082406` 为验收对象。此前可靠双轨、原文来源分离、导入、任务投影、转写路线和 VoiceOver 的稳定签名证据仍保留。

## 0. 记录规则

每组测试记录：Build Number、日期、允许/拒绝/稍后状态、截图路径、结果和备注。失败时保留 Woice 设置页、系统设置权限页和错误文案截图，不要通过反复点击或重置权限掩盖问题。

## 1. 工作台启动与窗口

1. 用 Finder 双击 `/Applications/Woice.app`，确认 Dock、菜单栏和唯一工作台窗口出现。
2. 依次按 `⌘1`、`⌘2`、`⌘3`、`⌘4`，确认进入素材库、处理任务、文字转音频、设置。
3. 在录音详情、处理任务和设置页面分别关闭窗口，再用 Dock 或 `open -a Woice` 重开。
4. 确认外层窗口标题始终为“Woice 工作台”，不能变成“录音详情”或其他页面标题；进程始终只有一个。
   菜单栏 Popover 可能在系统辅助功能树中显示为隐藏的 `Window` 对话框；只把可见的“Woice 工作台”算作主工作台，不把它当成第二个应用窗口。
5. 从菜单栏执行“退出 Woice”，再双击启动，确认能完整重启。

通过条件：窗口可见、标题稳定、无第二进程/第二菜单栏图标、路由和设置草稿不异常丢失。

## 2. 菜单栏、工作台与按钮反馈

1. 点击菜单栏 Woice 图标，空闲态只确认四个动作：开始录音、进入工作台、设置、退出 Woice；不应出现最近结果、更多菜单、导入或文字转音频。
2. 记录 Popover 宽高和箭头位置：空闲高度不超过 260 pt，箭头下方到首个可见内容不超过 20 pt；录音和失败状态不超过 420 pt。
3. 点击“进入工作台”和“设置”，确认都复用同一个“Woice 工作台”窗口；关闭后从菜单栏再次打开，不应出现第二个工作台或第二个 Woice 进程。
4. 首次使用引导应出现在工作台右上角，不应撑大菜单栏 Popover；点击“打开录音设置”和“开始录音”分别验证路由和主动作。
5. 录音中返回菜单栏，确认第一个动作原位变为“结束录音”，计时和麦克风输入状态持续更新；点击退出需先显示保存确认。
6. 在素材库和素材详情确认“导入音视频…”与“开始录音”同时可见；处理任务、文字转音频和设置不显示导入主入口。
7. 点击“复制原文”“粘贴到当前应用”“刷新”“重新检查”等按钮，确认有按下态、处理中态、成功/失败反馈和 VoiceOver 文案。
8. 未授权辅助功能时，复制原文必须可用；自动粘贴必须明确失败原因和授权入口。

通过条件：四动作命令面板稳定、工作台唯一、按钮状态变化在 300 ms 内可感知；颜色不是唯一状态信号；键盘和 VoiceOver 能读出动作及结果。

## 3. 侧栏与密度

1. 将窗口拖到最小宽度，再分别调整侧栏约 280 pt、320 pt、360 pt。
2. 检查中文和英文标题、日期、时长、来源、状态没有单字纵向换行或遮挡。
3. 在素材库使用搜索、状态筛选“全部/处理中/部分就绪/失败”，验证无结果时有清除动作。

通过条件：布局在窄窗口和放大字体下仍能完成核心操作。

## 4. 设置分区独立保存

1. 在“录音与输入”修改一项但不保存，切换到“模型与转写”，确认草稿仍隔离。
2. 保存录音分区，确认不弹出 API Key/Keychain 授权。
3. 在“模型与转写”修改模型、语言或 Endpoint，单独保存并确认只提交该分区。
4. 在“文件与隐私”修改导出目录，单独保存；重新打开设置确认其他分区不被回滚。
5. 只有明确保存 API Key 时才验证 Keychain 弹窗；普通设置保存不得触发它。

通过条件：分区保存互不阻塞、普通保存不请求 Keychain、密钥不出现在界面日志或素材目录。

## 5. TCC A→B 连续性

### 4.1 安装 A

如需重新走一次 A→B，先关闭窗口，再执行以下命令。`mss07r-v2` 只是备份标签，避免覆盖历史证据：

```bash
WOICE_RUN_STABLE_UPGRADE=1 \
WOICE_STABLE_SIGNING_IDENTITY='Apple Development: jianglewis@126.com (23RRB32DPL)' \
WOICE_STABLE_PHASE=A \
WOICE_STABLE_REUSE_OUTPUT=1 \
WOICE_STABLE_BUILD_A=2026082331 WOICE_STABLE_BUILD_B=2026082332 \
WOICE_STABLE_BACKUP_TAG=task-a11y-projection \
WOICE_STABLE_OUTPUT_ROOT=/private/tmp/woice-stable-ab-20260823-task-a11y-projection \
./scripts/acceptance_stable_upgrade.sh
```

启动 A 后：

- 设置 → 录音与输入：按需允许麦克风，返回后点“重新检查”。
- 开启会议模式：按提示在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许 Woice，返回后重新检查。
- 选择本机 Speech 转写时才请求语音识别。
- 只有开启自动粘贴时请求辅助功能；复制原文不请求。
- 关闭并重开 Woice，记录 A 的四项状态。

### 4.2 覆盖 B

完成 A 的授权记录后执行：

```bash
WOICE_RUN_STABLE_UPGRADE=1 \
WOICE_STABLE_SIGNING_IDENTITY='Apple Development: jianglewis@126.com (23RRB32DPL)' \
WOICE_STABLE_PHASE=B \
WOICE_STABLE_REUSE_OUTPUT=1 \
WOICE_STABLE_BUILD_A=2026082331 WOICE_STABLE_BUILD_B=2026082332 \
WOICE_STABLE_BACKUP_TAG=task-a11y-projection \
WOICE_STABLE_OUTPUT_ROOT=/private/tmp/woice-stable-ab-20260823-task-a11y-projection \
./scripts/acceptance_stable_upgrade.sh
```

启动 B 后点击各项“重新检查”，逐一记录：

- 麦克风是否保持已授权且不重复弹窗；
- 系统音频运行时能力是否可读；
- Speech 是否保持授权；
- 辅助功能是否保持授权；
- 素材数量、设置草稿、当前模型是否保持。

如果从 ad hoc 迁移到稳定身份时出现一次“需要重新授权当前安装包”，允许并记录为迁移结果；重新打开后不得每次重复请求。不要把一次性迁移重新授权记为继承失败，也不要把未授权状态记为通过。

## 6. 快捷键手动路径（本轮不由 Codex 执行）

1. 设置 → 录音与输入，点击快捷键录入框，按一个未使用的组合（例如 `⌘⇧R`）；确认显示规范化组合和“可用”。
2. 点击保存，关闭设置后重新打开；确认快捷键仍显示，按组合开始/结束录音。
3. 再录入 `Escape` 或只有修饰键；确认在保存前显示“不支持”，当前快捷键不被卸载。
4. 录入一个已知被其他应用占用的组合；确认显示“当前可注册性检查失败/已被占用”，保存失败后旧快捷键仍有效。
5. 选择“关闭快捷键”并保存；确认不会请求输入监控权限，之后按旧组合不会启动录音。
6. 恢复 `⌥Space`，作为后续手动验证的默认状态。

通过条件：录入、取消、冲突、关闭和恢复都不产生两个快捷键，也不留下无快捷键的中间态。

## 7. Dock/Finder 图标手动路径（本轮不由 Codex 执行）

1. 退出 Woice，打开 Finder 的“应用程序”，观察 `/Applications/Woice.app` 图标；再从 Dock、Launchpad 和应用切换器各观察一次。
2. 确认白底图标由 macOS 显示系统圆角矩形，不是硬直角白色方块；W 主标居中、不裁切。
3. 在同一 Dock 大小下对比相邻系统 App；记录浅色、深色模式下的视觉尺寸和边缘。

通过条件：四个系统入口使用同一个 Bundle AppIcon；若仍是方块，只记录截图和系统版本，不手工给 PNG 叠圆角。

## 8. 真实素材手动路径（本轮不由 Codex 执行）

### 5.1 麦克风录音

允许麦克风后点击开始录音，说一句完整短句，观察计时、电平、停止后的 WAV 落盘和原文；停止后确认不会自动进入文字转音频或自动朗读。

### 5.2 系统声音/会议

允许系统音频后播放一个本机视频或会议测试声源，开启会议模式并录音；麦克风说一句与视频不同的内容。停止后分别检查麦克风 WAV、系统声音 CAF、会议合成音频、时长和峰值，并确认最终原文只显示两边说话内容、不插入声音来源；来源应在“时间戳片段”和 JSON 的 `sourceTrack` 中可见。系统声音文件为空、静音或最终原文缺少任一路时均不通过。

### 5.3 文件导入

通过“导入音视频…”选择 WAV、MP3/M4A 和 MP4/MOV 各一份，确认原件先落盘、同一 Sheet 出现“转文字”、失败时可“稍后处理/重新转写”，原件 SHA-256 不变。视频无音轨或损坏时应响亮失败且不留下伪造素材；当前自动桌面证据已覆盖这两种边界，真实用户文件仍需手动确认。

### 5.4 长文件与第三方 Provider

使用真实长文件和真实 Provider 检查分段、恢复、时间戳合并、失败重试和外发确认；确认原件不变、不会静默截断、不自动无限重试。

### 5.5 MSS-07R 转写连续性

1. 在设置中将 ASR 指向本机 loopback 服务，完成一次健康检查；保存模型、语言和时间戳配置后退出并重新打开 Woice。
2. 开启会议模式录制一段同时有麦克风和电脑声音的素材；停止后确认直接显示“正在本机服务转写”或工作台任务状态，不出现菜单栏“继续发送”确认框。
3. 打开工作台“处理任务”，确认同一会议显示麦克风和电脑声音两条受控转写任务，最终汇总为一份原文；不要重复点击“按声音片段转写”制造竞争任务。
4. 将 ASR 改为云端或未验证服务，录音停止后从工作台确认外发；点击“稍后处理”，确认任务显示“待处理/可继续”，而不是“已取消”。
5. 退出并重开 Woice，在工作台打开同一任务，点击“继续处理”；确认只有在本次明确确认后才发送，且任务列表没有重复活动转写。
6. 修改 loopback Endpoint、模型、语言或时间戳选项之一并单独保存，确认下次录音重新要求健康检查；API Key 变化本身不应使本机信任摘要泄露密钥。

通过条件：本机已验证服务重启后不弹确认；外发确认只在工作台出现；“稍后处理”可恢复；同一素材的主转写与声音片段任务不并行重复。

## 9. 无障碍与视觉矩阵

1. 在系统设置开启 VoiceOver，按 Tab/方向键完成工作区切换、搜索、选择素材和打开设置。
2. 开启高对比度，检查图标 + 文字 + 颜色三重状态表达。
3. 开启 Reduce Motion，确认反馈仍清晰但不播放不必要动画。
4. 将字体放大到 120% 和 200%，检查侧栏、列表、详情和设置不截断关键动作。
5. 在浅色、深色模式各截一张工作台、设置、任务和素材详情图。

通过条件：无 VoiceOver 阻断、无仅依赖颜色的状态、无关键按钮不可达或被截断。
