# 模型选择可见性与本机 Qwen 安装修复规格

> 状态：已实现；真实 UI 手测待用户确认
> 日期：2026-08-25

## 目标

- 在“模型与转写”页首屏可看到已验证、已安装的本机模型。
- 不进入高级设置也能切换 Tiny、Large-v3、Qwen3-ASR 等已安装模型。
- 切换后立即更新下一次本机转写目标，并同步设置草稿，避免后续保存其他设置时回退模型选择。
- 生成带已校验 Qwen3-ASR 0.6B 模型包的最新 Offline App，并覆盖安装到本机。

## 范围

- `ProvidersSettingsPane` 的本机模型选择入口与模型列表投影。
- 已安装模型切换状态、错误反馈和设置草稿同步。
- Qwen 模型包 manifest、Offline 打包、签名校验与本机覆盖安装。

## 非目标

- 不改变模型权重、Provider 协议或录音/转写数据结构。
- 不把 Qwen 放入未通过签名 Catalog 的 Store 下载入口。
- 不删除用户录音、原文、现有模型或设置。

## 验收标准

- 已安装模型数量大于 0 时，模型与转写页首屏显示模型菜单和当前模型；菜单列出每个已验证模型的名称、版本和来源。
- 点击 Qwen 后，菜单显示切换中，成功后当前转写目标、设置值和 Provider 三者一致；失败时原模型不变且显示可执行错误。
- 保存模型以外的服务设置不会把已切换模型回退。
- Offline App 包含 Qwen manifest、5 个模型文件和 MLX Metal Bundle；逐文件 SHA-256、Bundle 签名和启动前资源门禁通过。
- 覆盖安装只替换 `/Applications/Woice.app`，保留 `~/Library/Application Support/Woice` 用户数据。
