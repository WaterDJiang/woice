# 转写模型路由单一真相源

## 目标

麦克风、系统声音、会议混音和导入音视频统一使用设置页当前选定的转写目标。默认目标是已安装的本机模型；只有用户明确选择并保存自定义服务时，才使用用户填写的 Endpoint 与模型 ID。

## 范围

- 新设置默认选择本机模型。
- 旧 `automatic` 仅作为兼容值，运行语义等同本机模型；保存过但未启用的 Endpoint 不得隐式覆盖本机路线。
- 下载、导入或切换已安装模型后，该模型成为当前本机转写目标。
- 套用自定义服务预设或在设置页明确选择“自定义服务”并保存后，使用对应 Endpoint、模型 ID 和独立密钥。
- 录音停止、导入后转写、已有素材重试和会议来源分离共用同一路由判断。
- `ProcessingTask` 必须保存实际执行的 Provider、模型、版本和数据位置，不得只展示已安装模型信息。

## 非目标

- 不删除用户保存的自定义 Endpoint；切回本机后将其保留为未启用配置，便于以后再次选择。
- 不在本机模型失败后自动改用自定义或云端服务。
- 不改变原始音频、Transcript Artifact 版本链和外发确认边界。

## 验收标准

- AC-001：新安装或无设置时使用已安装/内置本机 Provider，不建立 HTTP 请求。
- AC-002：旧 `automatic` 即使保留 Endpoint，也使用本机 Provider。
- AC-003：用户明确选择自定义服务时，麦克风、系统声音、会议混音和导入文件使用所选 Endpoint/模型。
- AC-004：从自定义服务切换任一已安装模型后，后续和重试任务使用该本机模型；保存的 Endpoint 不被删除。
- AC-005：设置页仅在当前路线为本机且模型版本匹配时显示“当前使用”；外部路线下可对已选本机版本执行“使用此模型”。
- AC-006：失败的外部任务在切回本机后重试，会刷新任务快照为本机 Provider，不再次进入端口确认。
- AC-007：切回本机时撤回尚未确认的 ASR HTTP 请求并保留为可重试任务；重启也不得恢复旧端口确认。
- AC-008：定向测试、`make test`、`make docs-check`、`make harness-check`、`make lint` 通过。

## 迁移裁决

- 替代：`automatic` 根据 Endpoint 是否非空隐式选择外部服务的行为。
- 保留：显式 `.external` 配置、API Key Keychain 隔离、本机服务健康检查与外发确认。
- 迁移：设置页三项选择收敛为“本机模型”和“自定义服务”；旧 `automatic` 继续可解码但不再出现在新 UI。
- 停止：模型清单显示“当前使用”但实际任务走另一 Provider 的双重状态。
