# 直接发行包模型下载重试

状态：代码与自动门禁完成；真实 WhisperKit 下载验收通过

## 目标

Core 与 Offline 发行包在用户点击下载 WhisperKit 或 Qwen3-ASR 模型时，遇到 Hugging Face CDN 的瞬时 TLS、连接中断或超时，不应立即把一次可恢复的下载标记为失败。

## 范围

- 为 WhisperKit Hub 快照增加应用层有限重试；每次重试重新获取文件元数据，并复用已完成的本地缓存。
- 为通用模型包逐文件下载增加同样的有限重试，并保留现有 Range 续传和原子安装语义。
- 取消、HTTP 4xx/5xx、清单校验和磁盘空间错误不自动吞掉；错误仍写入持久化下载任务。
- 不改变 Core 无内置模型、Offline 的 bundled 模型、App Store 清单信任边界或模型版本固定值。

## 验收标准

- 瞬时 `NSURLError` 后的下一次尝试能够继续下载并完成安装；旧模型、录音和安装指针在失败期间不改变。
- `CancellationError` 不触发重试，已有部分文件仍可由用户再次点击恢复。
- 不可恢复错误在有限次数后明确显示，并持久化为 failed 状态。
- 新增重试策略单元测试；完整 Swift 门禁通过。
- 重新构建并检查 Core/Offline 包中的新代码，包内模型库存与签名边界保持不变。
