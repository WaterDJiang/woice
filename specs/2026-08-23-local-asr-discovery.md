# 本机 ASR 服务发现与模型列表

## 目标

在用户主动点击时探测已填写的本机/局域网 ASR 服务，读取兼容的 `/v1/models` 列表，帮助选择模型；不在启动、打开设置或录音流程中自动探测。

## 约束

- 只允许 `http`/`https`，且目标必须是 `localhost`、回环地址或 RFC1918 私网地址；公网 Endpoint 不执行发现。
- 单次请求超时不超过 5 秒，失败只显示错误，不改变已保存配置。
- 支持 OpenAI-compatible `{ "data": [{ "id": "..." }] }`；响应不兼容时回退为“手动填写模型”。
- API Key 只从内存/Keychain 读取，日志和错误不包含密钥。
- 发现只是读取服务元数据，不上传音频、不创建 Recording/Job。

## 验收

- 未点击“发现模型”前零网络请求。
- loopback Fixture 返回模型列表后可选择模型；慢响应、端口占用、HTTP 错误和非法 JSON 均有可读失败。
- 公网 Endpoint 被 fail-closed 拒绝。
- 设置草稿中的模型可更新，但保存前不改变 AppState 路由。
