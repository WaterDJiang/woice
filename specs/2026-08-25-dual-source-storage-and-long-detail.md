# 双音源、压缩存储与长素材详情性能规格

## 2026-09-01 真实会议验收裁决

- 会议合成文件是用于复听和导出的压缩派生物：双轨输入统一为单声道 48 kHz AAC/M4A；真正送入任意 ASR Provider 前，再由受控准备层生成临时 16 kHz 单声道输入，不把第三份 PCM 当作永久素材。
- 默认 `sourceSeparated` 语义保持不变：会议合成文件必须生成，但转写任务分别指向可用的麦克风与系统音频原轨，最后按时间线合并；只有显式 `standardMix` 才把会议合成作为单一转写输入。
- 真实 ScreenCaptureKit 验收必须同时检查系统音频文件可读、峰值/时长、会议合成可读和任务来源，不能用“会议合成存在”推断它已经是默认 ASR 输入。

## 目标

- 工作台顶部以“麦克风”“电脑声音”两个独立按钮控制下一次录音来源，首次及缺省状态均为双开。
- 麦克风、电脑声音可以分别关闭；两者均关闭时保留选择，但禁止开始录音并说明原因。
- 录音开始后锁定本次来源，停止后恢复切换；界面始终显示实际采集来源。
- 双开时保留麦克风原轨、电脑声音原轨并生成会议合成文件；单开时只生成所选原轨，不申请另一音源权限。
- 新录音使用适合长时语音的压缩存储，保留分段固化、异常恢复、原始 Artifact 不覆盖和本机转写边界。
- 长素材详情在不预热所有音轨、不一次构建全部时间戳行的前提下快速打开；原文在固定内容窗口内独立滚动。

## 非目标

- 不自动猜测用户需要的声源。
- 不允许录音中途改变本次声源集合。
- 不自动转码、覆盖或删除既有 PCM/WAV/CAF 素材。
- 不改变双轨分别转写、时间线合并和声音来源只进入时间戳/JSON 的语义。

## 录音来源契约

| 麦克风 | 电脑声音 | 开始录音 | 永久音频 Artifact |
|---|---|---|---|
| 开 | 开 | 允许 | 麦克风原轨、电脑声音原轨、会议合成文件 |
| 开 | 关 | 允许 | 麦克风原轨 |
| 关 | 开 | 允许 | 电脑声音原轨 |
| 关 | 关 | 禁止 | 无 |

- 两个按钮是录音来源的唯一工作台入口；设置页可以说明默认值，但不得保留冲突的“录制电脑声音”总开关。
- 缺省设置为双开；旧设置迁移时保留用户已有的电脑声音选择，麦克风保持开启。
- 只录电脑声音时不得创建麦克风文件、请求麦克风权限或用麦克风状态判定录音失败。
- 双开时任一轨失败不得删除另一条已固化音轨；最终状态说明缺失来源。

## 存储契约

- 新录音最终文件不得继续使用当前 48 kHz Float32 PCM 作为默认长期格式。
- 默认语音优化档：麦克风 48 kHz 单声道 AAC-LC 64 kbps；电脑声音 48 kHz AAC-LC 96～128 kbps；会议合成使用压缩单声道文件。
- 新录音直接写入 AAC/M4A；会话 Journal 在采集前提交，停止后只有文件可解码且 Recording 元数据提交成功才显示为素材。现有 VAD 分段继续用于后台转写，不额外保留永久 PCM 副本。
- ASR 需要的 16 kHz 单声道音频是可再生工作文件，不作为第三份永久原件。
- 55 分钟目标：麦克风单轨不高于 35 MB，电脑声音单轨不高于 60 MB，双轨加会议合成不高于 120 MB。
- 既有 PCM 素材保持原样；后续“优化存储空间”必须显式确认且旧原件只可移入废纸篓。

## 详情页契约

- 详情首屏只读取 Recording 元数据，不同步初始化 `AVAudioPlayer`，不读取完整音频。
- 只显示一个播放器；以“麦克风原轨 / 电脑声音 / 会议合成”切换当前音轨，点击播放时才异步打开该文件。
- 顶部摘要只保留一个播放器；原文与时间轴使用固定高度内容窗口，各自在窗口内独立滚动，不再随内容无限拉长详情页。
- 原文使用适合大文本选择/复制的固定高度原生文本区域；正文长度不得扩展整个详情页。
- 时间轴使用懒加载容器；长列表只构建可见附近的行。
- 切换素材或离开详情时取消尚未完成的音频准备，并释放播放器。

## 验收标准

- 双音源四种组合均有确定性测试；双关时 `startRecording` fail-closed，且不创建任何文件。
- 系统音频单轨录制不访问麦克风；麦克风单轨不启动 ScreenCaptureKit。
- 双轨转写和合并契约保持通过，会议合成文件存在且可播放。
- 压缩文件时长与录音时长误差不超过 250 ms，能被当前本机 ASR 与导出链读取。
- 60 分钟、1,000 个时间戳片段的 Fixture：详情框架 300 ms 内可见；主线程不执行完整音频读取；打开详情新增 RSS 不超过 50 MB。
- 键盘能切换两个音源按钮、播放器音轨和内容页；VoiceOver 同时朗读音源名称、开关状态、锁定状态和双关失败原因。
- `make verify`、Store 条件回归、正式 Xcode Store 无签名构建和覆盖安装通过。

## 影响面

- Domain/Settings：录音来源持久化与旧设置迁移。
- Runtime：开始/停止状态机、单独系统音频录制、失败与恢复。
- Audio/Storage：分段固化、压缩编码、会议合成和旧格式兼容。
- UI：工作台音源按钮、菜单栏状态、详情播放器与内容区域。
- Tests/Docs：来源矩阵、压缩可读性、长列表性能、规格/计划/日志索引。
