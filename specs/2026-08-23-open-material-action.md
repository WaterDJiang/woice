# R2 素材外部打开动作

## 目标

在录音详情中把已保存的原始音频交给 macOS 默认应用或 Finder，形成“素材可引用”的最后一公里；不改变原始文件和数据库事实。

## 约束

- 只打开已经存在且属于当前 Recording 的文件：麦克风 WAV、系统声音 CAF、会议合成 WAV。
- 不先导出、不复制、不覆盖原始文件；缺失文件给出可执行错误。
- Finder 显示动作只选择已存在的文件；默认播放器动作只打开用户明确点击的单个文件。
- UI 反馈必须说明打开/显示是否成功，失败不伪造完成。

## 验收

- 详情“打开”菜单能显示素材文件并分别打开麦克风/系统音频/会议合成音频。
- 没有系统音频或 meetingMix 时对应动作禁用。
- 原始音频 SHA-256、RecordingRecord 和 ProcessingTask 在动作前后不变。
