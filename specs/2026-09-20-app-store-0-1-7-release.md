# App Store 0.1.7 (12) 更新

## 目标与授权

用户明确要求更新版本、发布至 App Store，并在审核通过后自动上线。本次发布方式采用自动发布，替代旧计划中的手动发布要求；无需再次确认提交或上线时间。

## 范围

以当前已安装验证的源码为基础，发布录音侧栏全生命周期状态优化。版本从线上 0.1.6 递增为 0.1.7，Build 从 11 递增为 12。现有价格、地区、隐私和截图沿用，不增加采集、外发、依赖或数据库迁移。

## 验收

- 版本元数据一致；Swift 测试、Store Bundle 检查、正式双架构 Archive 和签名通过。
- 上传后 Apple 构建处理完成，0.1.7 选择 Build 12；填写准确的更新说明。
- 发布选项保存并回读为审核通过后自动发布，提交审核并确认等待审核状态。
- 不把上传或等待审核说成已上线。真实录音 UI/TCC 未执行时如实记录。

## 兼容与影响

Dev 与 Store 通道隔离；历史录音和转写不迁移、不覆盖。不提交 Git、不推送源码。签名信息仅在本机进程和本机未跟踪导出配置中使用，不进入仓库或日志；保留历史 Store Archive。
