# 首次使用准备引导

## 目标

- 让第一次使用 Woice 的用户不需要理解 App Sandbox、TCC、Catalog 或 Provider，也能完成素材保存位置、麦克风权限和本机转写模型准备。
- 在触发系统面板或大体积下载前，先用一句白话说明“为什么需要”和“数据会去哪里”。
- 引导、工作台空状态和设置页展示同一组就绪事实，不出现一处显示完成、另一处仍显示缺失。

## 范围

- 首次使用改为一个可关闭的清单式 Sheet，核心步骤固定为：
  - 选择素材保存文件夹。
  - 允许麦克风并确认有可用输入。
  - 在 Tiny、Qwen3-ASR、Large-v3 三个本机转写模型中选择并下载；三个选项全部可见，按当前 Mac 能力排序推荐。
- 电脑声音权限作为明确标注的可选步骤；只在用户点击后请求屏幕录制权限，同时说明 Woice 只读取系统音频，不保存屏幕画面。
- 麦克风未决定时提供“允许麦克风”；被拒绝时提供“打开系统设置”；已允许但无输入时提供声音设置入口。
- 不再在 App 启动后立即弹出保存面板；只有用户在引导或录音/导入动作中主动选择时才打开。
- 引导可选择“稍后设置”；未下载模型不阻止保存录音，但明确说明暂时不会生成文字。
- 设置侧边栏对缺少素材文件夹、麦克风权限或本机模型显示可执行摘要和橙色状态，完成后改为就绪。

## 不在范围

- 不把 Accessibility、Input Monitoring、Agent 或云端服务授权加入首次使用必选步骤。
- 不自动开始录音、下载模型、打开系统设置或获取电脑声音权限。
- 不改变模型 Catalog、下载校验、原始素材不可覆盖和本地优先语义。

## 验收标准

- 全新 Store 数据状态启动后先看到 Woice 内的准备说明，不立即看到无上下文的 `NSSavePanel` 或 TCC 弹窗。
- 三个核心步骤各自显示“待完成 / 进行中 / 已就绪”图标和文字，并显示已完成数量。
- 清单首次打开固定从第 1 步开始，不把保存位置藏在滚动区域上方。
- 点击选择保存位置后才出现标准保存面板；成功后立即显示选定文件夹名称和“用户可直接打开”。
- 点击麦克风授权后才触发系统弹窗；拒绝、无输入和成功状态都有不超过两个动作的下一步。
- 模型下载同时列出 Tiny、Qwen3-ASR、Large-v3，逐项显示大小、资源影响、质量取舍、适用场景和当前 Mac 的推荐理由；保存在这台 Mac、不上传录音，并展示进度、失败与重试。
- 推荐项排在最前并明确标注“为这台 Mac 推荐”，但不隐藏或禁用另外两个已验证选项；安装任一模型后清单和设置页都显示已就绪，用户仍可下载其它模型。
- 全新安装尚无已验证模型清单时，第 3 步直接提供“检查可下载模型”，并说明它只获取小型签名清单，模型仍需下一步确认后下载。
- 电脑声音步骤明确显示“可选”和“不保存屏幕画面”；未点击时不触发系统权限。
- 只有素材文件夹和麦克风可用时，“开始第一段录音”才可用；模型未安装时按钮旁明确提示“可以录音，暂不会转成文字”。
- VoiceOver 能读出步骤名称、状态、用途和动作；键盘可完成所有按钮操作。
- 定向测试、全量 Swift 测试、Store 条件测试、`make xcode-build-store`、文档/Harness/lint 和稳定签名安装通过后，再交给真实桌面手测。

## 影响面

- `WorkspaceView`、首次使用视图、`AppState`、`RecordingService`、`SettingsView`、`MaterialLibraryPanel`。
- 首次使用投影与权限动作的定向测试、App Store 上架计划和执行日志。
