# 模型库存扫描隔离规格

## 目标

- 一个损坏、过期或半安装的模型版本不能阻塞其它已验证模型在设置页显示和切换。
- 库存列表只返回通过完整清单、路径、文件类型、字节数和 SHA-256 校验的模型包。
- 运行时使用具体模型前仍必须再次严格校验；本规格不把跳过扫描的包当作可用模型。

## 范围

- `ModelPackStore.inventory()` 的 bundled/downloaded 目录扫描。
- 模型设置页依赖的已安装模型列表与版本切换可见性。
- 新增损坏版本与有效版本共存的自动回归。

## 规则

- 每个模型版本独立校验；某一版本失败时隔离该版本，继续扫描同一模型包的其它版本和其它模型包。
- 目录读取、权限或根目录不可访问等全局故障仍可抛出；不能用“空库存”掩盖整个模型根目录不可读。
- `installedDirectory(for:)`、`bundledDirectory(for:)` 和安装流程保持 fail-closed，不因库存扫描变更而放宽校验。
- 不自动删除、修复或覆盖损坏版本；用户仍可通过明确的删除/重新安装动作处理。

## 验收

- 有效 Qwen/Whisper 版本与一个损坏版本共存时，库存仍返回所有有效版本。
- 损坏版本不会出现在模型切换菜单，也不会被选为当前模型。
- 有效版本的 current 指针、目录校验和删除保护保持不变。
- `make test`、`make verify`、`make docs-check`、`make harness-check` 与 `git diff --check` 通过。

## 非目标

- 不改变模型下载、安装、回滚、签名 Catalog 或正式发行条件。
- 不把未校验或未知 Runtime 的模型加入库存。
