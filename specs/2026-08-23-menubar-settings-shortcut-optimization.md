# 菜单栏、设置、快捷键与 Dock 图标优化实施规格

> 状态：代码与自动门禁完成；真实 Mac 视觉、TCC、VoiceOver 和 Provider Journey 待验收
> 日期：2026-08-23
> 关联计划：`doc/plan/2026-08-23-menubar-settings-shortcut-optimization.md`

## 目标

- 菜单栏只承担录音控制和三个应用级入口：进入工作台、设置、退出。
- Popover 使用实际内容高度，不再保留固定顶部空白。
- 设置默认层只呈现可直接决策的用户语言；低频诊断和实现细节进入高级区域。
- 录音快捷键从固定预设迁移为可编码的键码 + 修饰键值，保存前可探测冲突，切换失败可回滚。
- Bundle AppIcon 作为 Dock/Finder/Launchpad 唯一发布真相，运行时不再覆盖原始 PNG。
- 录音详情按“我的声音（麦克风）/电脑声音/会议完整回放/检测到的有声片段”分层展示，并保持本地与外部转写边界。

## 不变约束

- 原始音频、原始转录不可覆盖；所有重转写都是新 Artifact。
- 录音必须来自用户可见动作或已配置的注册式快捷键；不安装 Event Tap、不请求输入监控权限。
- 本地 Provider 失败不隐式降级到云端；外部服务仍需明确确认。
- 设置按录音、服务、文件三个分区独立保存，密钥只在服务字段变更时访问安全存储。
- AppKit `NSStatusItem`、336 pt 宽度、唯一工作台窗口和 `microphone/systemAudio/meetingMix` 内部枚举保持不变。

## MSS-07R：本机服务信任连续性与非阻塞转写（增量）

### 目标

修复真实菜单栏 Journey 暴露的两类回归：本机 loopback 服务在 App 重启后丢失显式健康检查事实，以及外部转写确认遮挡菜单栏和录音状态。转写任务必须可恢复，会议录音只允许一个活动主转写策略。

### 范围

- 将本机服务健康检查事实持久化，并绑定标准化 Endpoint、模型、语言/时间戳等不含密钥的配置摘要；配置变化后自动失效。
- 移除菜单栏转写确认 Alert；本机已验证服务直接转写，需外发的确认与继续入口统一在工作台任务区域呈现。
- “稍后处理”保持任务为可恢复的 `queued` 状态；重启后工作台仍显示明确的继续入口。
- 主转写任务处于等待、运行或处理中时，不创建重复声音片段任务；切换会议转写模式只能创建新的任务/Artifact 版本。
- 工作台确认卡的 VoiceOver 名称必须包含实际目标标题，按钮状态与可见文案一致，不得朗读源码占位文本。
- 菜单栏录音状态、输入活动和快捷键冲突提示中的动态值必须使用运行时插值；可见文字与 VoiceOver 值不能出现源码占位文本。

### 验收

- `make test` 覆盖信任快照读写、配置失效、稍后处理不取消、重启恢复和主/片段任务去重。
- 静态检查确认 `MenuBarPopover` 不再挂载转写 `.alert`，工作台提供确认/稍后/继续入口。
- 静态检查确认确认卡使用运行时字符串插值生成可访问名称，并保留“确认并开始/稍后处理”两个独立操作。
- 静态检查确认菜单栏录音时长/输入状态和快捷键候选名称均使用运行时插值。
- 真实 Mac Journey：健康检查 -> 重启 App -> 双轨录音 -> 自动完成会议完整回放转写，全程无确认弹窗；云端确认 -> 稍后处理 -> 重启 -> 工作台继续转写。
