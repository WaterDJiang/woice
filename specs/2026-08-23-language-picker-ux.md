# 识别语言选择体验规格

## 目标

把设置页的“识别语言”从裸代码输入改为原生语言选择，降低 `zh`/`en` 等内部代码带来的理解成本，同时保持旧配置和 Provider 契约兼容。

## 范围

- 录音与转写设置中的识别语言控件改为原生 `Picker` 菜单。
- 首层提供“自动检测（推荐）”、简体中文、繁体中文、English、日本語、한국어、西班牙语、法语和德语。
- 已有 `zh`、`zh-CN`、`en` 等代码显示为语言名称；未知旧值保留并显示为“当前配置（代码）”，不得静默改写。
- “自动检测”使用空字符串保存，继续满足现有 Provider 的空语言参数语义。
- 本机 Speech 实时预览和最终识别不支持真正的多语种自动检测时，使用系统首选语言作为明确的本机回退；WhisperKit 和外部兼容接口继续接收空值以使用各自的自动检测能力。
- 代码只在辅助说明中出现，不作为主标签；不引入网络查询或自动扫描语言列表。

## 约束

- `AppSettings.language` 继续保持 `String`，避免数据库、旧设置和 Provider Schema 迁移。
- 选择语言只修改当前设置草稿，仍由录音分区的独立保存动作提交。
- 不改变本机实时预览和最终转写的授权、外发和模型路由。

## 验收标准

- `zh`、`zh-CN`、`en`、空值分别映射为可读名称，未知代码可往返保存。
- 选择“自动检测”后持久化值为空字符串；选择常用语言后保存规范代码。
- 自动检测不会再静默固定为中文；本机 Speech 的回退语言来自 macOS 首选语言。
- 设置页不再渲染 `TextField("zh")` 作为识别语言主控件。
- 现有设置分区独立保存、Keychain 访问范围和转写请求参数测试继续通过。

## 替代、保留、迁移、停止、顺序

- 替代：替代设置页的语言代码自由文本输入。
- 保留：`AppSettings.language` 字符串字段、旧配置解码和 Provider 传参契约。
- 迁移：仅在 UI 层把旧代码投影为语言名称；未知值继续作为自定义代码展示。
- 停止：不再把 `zh` 作为新安装的可见默认文案，也不自动猜测未知代码。
- 顺序：属于 R0/M2-08 设置体验收口；先于真实桌面设置 Journey，不改变 R1 模型和 R3 Agent 顺序。
